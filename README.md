# Inventory-Qi

***Sistema de consulta y monitoreo de existencias diseñado para la visualización de datos provenientes de CONTPAQi® Comercial.***

## Modulos del sistema

- Visualizador de inventario
- Reporteador de inventario fisico vs sistema
- Control de acceso al sistema
